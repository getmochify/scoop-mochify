# scoop-mochify

A [Scoop](https://scoop.sh) bucket for [Mochify](https://mochify.app) — the `mochify` CLI and MCP server for fast, privacy-first image compression and conversion (AVIF, JXL, WebP, Jpegli), plus PDF split/rasterize.

## Install

```powershell
scoop bucket add mochify https://github.com/getmochify/scoop-mochify
scoop install mochify
```

## Update

```powershell
scoop update mochify
```

## Notes

The `mochify.json` manifest is updated automatically on each [mochify-cli](https://github.com/getmochify/mochify-cli) release — please don't edit it by hand.
